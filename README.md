# Still Here

To add your own photos and music, upload them to these folders:

- `assets/photos/` → `photo1.jpg`, `photo2.jpg`, `photo3.jpg`
- `assets/music/`  → `song.mp3`

On github.com: open the folder → Add file → Upload files → Commit.
The live site updates about a minute later.

## Cat animation

Download the cat from LottieFiles as **Lottie JSON** and upload it as `assets/cat.json`.
If the file isn't there, the site shows its own drawn cat.
